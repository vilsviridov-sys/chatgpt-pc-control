# chatgpt-pc-control
Бесплатная система управления компьютером с помощью ChatGPT, с локальным агентом и веб-интерфейсом.Цель проекта

Создать систему, позволяющую управлять компьютером Windows 11 через интеллектуального помощника.

Основные возможности

- Управление файлами.
- Работа с браузером.
- Запуск программ.
- Создание и редактирование кода.
- Выполнение команд.
- Управление через веб-интерфейс.
- Подтверждение важных действий пользователем.

Архитектура

1. ChatGPT — анализ задач и подготовка инструкций.
2. Web Interface — интерфейс управления.
3. Local Agent — исполнитель команд на компьютере.
4. Security Layer — проверка и подтверждение действий.

Технологии

- HTML
- CSS
- JavaScript
- Python
- GitHub

Безопасность

- Ограничение доступа к файлам.
- Подтверждение опасных операций.
- Запрет скрытого выполнения команд.
- Защита паролей и секретных ключей.

Статус
